description: Interview the user about a plan, a design or a project's open questions until you share one understanding of it, settling each question in turn. Use when goals, plans or decisions are unclear, or when the user asks to be grilled.
---

# Grill me

Settle what is open, one question at a time, until you and the user agree on every branch that matters.

1. **Find what is open.** From the project's goals, plans, notes, code and current chats, list the decisions that are not made yet, the
   assumptions nobody stated, and the places where two sources disagree. Order them so that answering one can settle the ones after it.
2. **Ask one question at a time.** Say why it matters, the options you see, and the one you recommend with your reason. Ask it so a short
   answer settles it.
3. **Follow the answer.** If it opens a new branch, ask about that next. If it settles others, say which. Never ask about what the code or
   the documents already answer: look it up.
4. **Keep the record.** After each answer, restate the decision in one line. When the open list is empty, give the whole set of decisions
   and the next steps they lead to, and ask whether to write them down where the project keeps its plans.

Stop when the user says to, or when nothing open is left that would change what is built.
